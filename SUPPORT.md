# Support

## Where to ask for help

Use:

- **GitHub Discussions** for usage questions, setup help, and product discussion;
- **GitHub Issues** for bounded bugs and concrete feature requests;
- `SECURITY.md` for private security reporting guidance.

## Before opening a thread

Please check:

- `README.md`
- `QUICKSTART.md`
- `AGENTS.md`
- `docs/how-it-works.md`
- `docs/reference.md`

## When not to use public issues or discussions

Do **not** post:

- secrets, tokens, or private credentials;
- vulnerability details or exploit proof-of-concept;
- private customer or repository data you are not allowed to share.

## Response expectations

This is an experimental open source project with finite maintainer capacity.
Well-scoped reports, concrete repro steps, and clear environment details are
much easier to answer.
